## Ядро системы (Базовые правила)

### Размерные числа и обозначения

- **Стрелочки:** `↓` = размер вниз, `↑` = размер вверх. Каждая ступень = ×2 или /2.
- `5↓` = пять маленьких (= 5 / 2 = 2.5). `3↑` = три больших (= 3 × 2 = 6).
- **При сравнении:** привести к наибольшему размеру. `3↓` успеха = `[3/2] = 1` успех.
- **При сложении:** привести второе значение к первому. `3↑ + 5` = `6 + 5 = 11` (3↑ приведено к среднему).
- **Округление:** `[...]` — целая часть вниз. Применяется ко всем **не промежуточным** результатам.

### Проверки

- Бросок `[a]` кубиков d6 с эффективностью `[Эф]` (макс. значение на кубике для успеха).
- Эффективность по умолчанию = 3. Если >5 → преимущества, если <1 → помехи.
- **Рейтинг успеха (РУ)** = успехи − сложность (или успехи − успехи оппонента).
- **Правило 6 и 1:** 1 = два успеха, 6 = −1 успех. Если успехов < 0 → критическая неудача.

### Характеристики

Целое число от 3 до 5 с размером. При достижении 6 → рост размера (→ `3↑`). При 2 → уменьшение размера.

| Характеристика | По умолчанию | Описание |
|---|---|---|
| **Проворство** | У всех | Гибкость, контроль тела, ОД |
| **Сила** | У всех материальных | Физ. сила, ОД, урон |
| **Телосложение** | У всех материальных | Выносливость, тяжёлые доспехи |
| **Восприятие** | min(Внимательность, Реакция) | Реакция, внимательность, ОД не в свой ход |
| **Интеллект** | min(Память, Мышление) | Преимущества, знания |
| **Сила воли** | Почти у всех разумных | Стресс, концентрация, истощение |
| **Магия** | У магов | Сила заклинаний |

Характеристики имеют **модификаторы** от источников (тренировки, мастерство, знания, обстоятельства, состояние, конструкция, поддержка, усиление). Из одного источника — только один бонус + один штраф.

### Ресурсы

| Ресурс | Описание |
|--------|----------|
| **Энергия** | Поглощает истощение. Макс = 1 по умолчанию |
| **ОД (Очки Действий)** | Для любых действий. Макс = 5 + модификаторы от Проворства, Силы, Восприятия |
| **Истощение** | Накопление → слабость → обессиливание → потеря сознания |
| **Жетоны концентрации** | max 1 + модификаторы от Восприятия и Интеллекта |

### Бой

- **Удар (ближний):** Мастерство боя (3↓) против РУ Защиты. Урон = (Урон оружия − Сопротивление) × РУ.
- **Защита:** Избегать (1 ОД, эфф. 2) или Блокировать (2 ОД, эфф. от оружия).
- **Дальний бой:** Мастерство оружия против 1+Укрытие. Дальнобойность обычно 5 ипари.

### Инициатива

В детальном отыгрыше: Проверка на инициативу `[Восприятие]` против 0. Чем больше РУ → раньше ход.

## Типы правил (структура из документов)

### 1. Валюты (отдельно от правил)

Из документов:

- **ОС (Очки Создания):** у каждой расы своё (от 3 до 16+) — **это стоимость расы, а не лимит персонажа**. Лимит ОС определяется игрой (или задаётся вручную при свободном создании). Раса тратит ОС из этого бюджета.
- **ОЛ (Очки Личности):** зависят от возраста. Тратятся на особенности личности.
- **ОР (Очки Развития):** получаются за приключения. 1 ОР = 100 опыта. Усваиваются за 2 месяца (1 месяц при полном посвящении).
- **ОУ (Очки Умений):** свободное вложение в любые навыки, усвоение требует времени.
- **ОВ (Очки Вдохновения):** за озарения, тратятся немедленно, усваиваются мгновенно. Только на навыки (не на черты).
- **Очки развития интеллекта:** доступны при большом Интеллекте (1 при большом, 2 при огромном, 4 при гигантском). Тратятся на черты развития (Счётный разум, Ходячая энциклопедия и т.д.).

### 2. Характеристики (как тип правила)

Характеристики, которые могут быть у рас:
- Сила, Стойкость, Выносливость, Ловкость, Проворство, Восприятие, Интеллект, Магия, Память, Реакция, Внимательность, Мышление

Характеристики могут быть:
- **Базовыми** (определены расой, например: `Сила 3↓↓`, `Выносливость 4↓`)
- **Опционными** (`Магия 4↑` — можно взять или нет)
- **Производными** (Восприятие = min(Внимательность, Реакция), Интеллект = min(Память, Мышление))
- **Динамическими** (Сила конструкта = min(Стойкость, Энергоядро↓))

### 3. Расы (иерархия)

**Вид → Раса → Подвид:**
```
Вид: Человек
  ├── Раса: Алиерц (10 ОС, Характеристики: Выносливость 5, Опции: Магия 5)
  ├── Раса: Аэрон (12 ОС, ...)
  └── ...

Вид: Птицелюд
  └── Подвид: Маул (16 ОС, ...)
  
Вид: Зверолюд
  └── Подвид: Фэрис

Вид: Конструкт (особые правила)
  └── Тело + Разум + Энергоблок (покупаются отдельно за ОС)
```

Каждая раса/подвид:
- **Количество ОС** (напр. 10, 12, 16)
- **Характеристики** (базовые значения и опции)
- **Бесплатные черты** (врождённые)
- **Доступные черты** (можно выбрать на ОС)
- **Признаки** (ключевые слова, напр. "кукла, дерево")

### 4. Способности (Навыки и Черты)

Общая структура навыка из документов:

```
Навык
Название(x из N)
Стоимость a, b, c[, Трудность d]
[Требуется: ...]
Описание эффекта...
Признаки: навык, [категория], [метод развития ...]
[Улучшение]
Название улучшения
Стоимость a
Требуется: ...
Эффект...
```

**Ключевые типы способностей:**

| Тип | Ключевые признаки |
|-----|-------------------|
| **Навык** | Признак `навык`. Эффект всегда, если используется сознательно |
| **Черта** | Признак `черта`. Эффект всегда, вне зависимости от желания |
| **Действие** | `Действие(NОД)`. Требует траты ОД |
| **Процесс** | `Процесс(NОД)`. Действие из частей |
| **Реакция** | `Реакция(NОД)`. Срабатывает на событие |
| **Улучшение** | Модифицирует/расширяет родительский навык |
| **Множественный навык** | Параметризуется (Язык, Регион, Вид...). Можно брать много раз |
| **Черта развития** | Требует Очки развития интеллекта |

**Стоимость навыков:**
- Базовая стоимость первого уровня
- При развитии: каждый следующий уровень стоит на `[Трудность]` больше предыдущего
- Пример: стоимость 4, трудность 2 → 4, 6, 8, 10...
- Максимальный уровень: `Навык(x из N)`

**Признаки (ключевые слова):**
- `навык, черта` — базовые типы
- `действие, процесс, реакция` — тип затрат
- `движение, бег, нападение, ближний бой, дальний бой, защита, прыжок, поворот, отдых`
- `волшебство, магия ядра, магия крови, сила крови, путь волшебства, волшебник`
- `метод развития восприятия, метод развития интеллекта` — для бонусов к характеристикам
- `медицина, знание, множественный`
- `разум, развитие`

**Система требований (условия):**
- `Требуется навык X`
- `Требуется: минимум N уровня навыка`
- `Требуется: значение характеристики ≥ N`
- `Для изучения и использования необходимо не менее N↑ Интеллекта`
- `Для приобретения необходимо: минимум [x * 20] опыта волшебства`

### 5. Эффекты (статусы)

Из Базовых правил:
- **Слабость:** Сила, Восприятие и Интеллект снижены на размер
- **Обессиливание:** снижены на два размера
- **Неустойчивость:** помеха на проверки проворства, силы и попадания. Трата 1 ОД снимает
- **Потеря равновесия:** проверка на проворство, провал → падение
- **Упадок сил:** группа эффектов, действует только сильнейший

### 6. Волшебство (отдельная подсистема)

**Источники волшебства:** Магическое ядро, Волшебная кровь, Магический кристалл, Владыка
**Пути волшебства:** Волшебник, Псионик, Прислужник (Контрактник), Начертатель, Культиватор, Самоартифактор

Структура заклинания:
- Сложность, Время сотворения, Компоненты, Действие (время/поддержание)
- Проверка на сотворение: `[Магия источника] против [Сложность]` (зависит от пути)

**Магия крови:** подсистема с жертвой крови, обескровливанием, силами крови (усиление магии, скорости, надёжности, дальнобойности, длительности).

### 7. Ресурсы (как тип)

Из Базовых правил:
- Ресурс = 1 или 2 числа (текущее и максимум)
- Энергия, ОД, Истощение — ключевые
- Могут быть размерными или безразмерными

## Примечания по реализации

### Структура описания правил в документах

Каждое правило (навык, черта, действие) имеет:
1. **Название** + опционально `(х из N)` — уровень и максимальный уровень
2. **Стоимость** — число или массив через запятую
3. **Трудность** (опционально) — для развиваемых навыков
4. **Требования** (опционально) — условия изучения
5. **Описание** — текст эффекта/правила
6. **Признаки** — ключевые слова (через запятую)
7. **Улучшения** (опционально) — дочерние способности, расширяющие родительскую

### Группировка в документах

Навыки сгруппированы в **ветки** (skill trees):
- Развитие восприятия → Методы развития восприятия (Внимательность, Реакция, Ориентирование, Чтение следов, Поиск улик...)
- Развитие интеллекта → Методы развития интеллекта (Память, Мышление, Языки, Счёт, Науки, Медицина...)
- Ближний бой (Удар, Захват, Толчок, Защита, Движение...)
- Дальний бой
- Волшебство (по путям)

Улучшения навыков образуют **деревья зависимостей**: навык → улучшения → улучшения улучшений.

### Автоматические способности (из описания)

Пример из Умений:
```
Развитие восприятия (без стоимости)
Вы получаете +1 к Восприятию, если владеете минимум двумя методами развития восприятия со Стоимостью 1 или больше.
Бонус увеличивается до 2 — при двух методах со стоимостью 2+, и т.д.
```

Это **пассивная/автоматическая** способность — проверяет условия при создании/изменении персонажа.
