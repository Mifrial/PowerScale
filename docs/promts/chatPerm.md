Что делать: реализовать §7.19 — роли чата и видимость сообщений. Зафиксированные решения:
1. Chat НЕ знает о Game. Роли чата (ChatRole { code, label, permissions }, IChatType.roles?, MemberInfo.role?) — generic-концепция Chat; значения ролей задаёт Game ('gm'/'player'). Мок сообщений не фильтрует (у Chat нет доменной логики) — роли/visibility хранятся как данные, гейтит фронт.
2. Минимальные права ролей: chat.see_all у роли 'gm' (константа Constant/Chat/CHAT_PERMISSION_SEE_ALL) — ГМ видит все сообщения, включая скрытые. Полную матрицу прав не делаем (YAGNI).
3. Видимость сообщения: ChatMessage.visibility?: { all?: boolean; forRole?: string | string[]; forUsers?: number[] }. Чистая Utils/chatVisibility.isMessageVisible(message, chat, viewerId, roles): отправитель всегда видит своё; нет visibility/all !== false → всем; роль зрителя с chat.see_all → видно; forUsers содержит → видно; forRole = роли зрителя → видно; иначе скрыто. Скрытое полностью скрыто без плейсхолдера (ChatMessageList фильтрует).
4. Отправка с видимостью: IChatApi.sendMessage(..., speaker?, visibility?) → Store/chat.sendMessage → ChatInput.send(..., visibility?) + меню «Всем / Только ГМ / Выбранным» (мультиселект участников). Пропы allowVisibility + visibilityOptions от GameChatTab (игровой чат); любой участник может слать с видимостью; ChatThread/ChatMessenger — pass-through.
5. Синхронизация ролей игрового чата (Game пишет роли в чат): mockCreateGameChat(name, members?: { userId, role }[]) (сид из членов игры: owner/gm → 'gm', player → 'player'); mockSetChatMemberRole(chatId, userId, role | null) в mockChat; mockGames.addGameMember/updateGameMember/removeGameMember → синк роли в игровой чат по gameChatId; фикстуры игровых чатов привести к ролям игры.
