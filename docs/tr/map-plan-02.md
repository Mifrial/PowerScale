# Карты: фронтенд-срез

**Статус:** ~В РАБОТЕ~, 2026-11-06 — фронтенд переработан под черновик и публикацию; ждёт ручной проверки.
**Реализация:** ~VUE~ — готово, ~PHP~ — [`map-plan-01.md`](map-plan-01.md), ~МОК~ — свой mock.
**Опираться на:** ~PHP~ (контракт `map.*`), ~МОК~ (свой mock).

Просмотрщик и редактор карт без SVG-парсера, Leaflet и PixiJS. Подложка —
растровое изображение из `Core/File`; оверлеи — Canvas 2D.

## Страницы

- `/maps` — список карт: название, видимость, обновление, кнопка «Новая карта».
  Фильтры: `q`, архив.
- `/maps/:id` — карта: «Просмотр», «Редактор», «Маршрут».

## Черновик

Редактор не пишет на сервер по действию. Он работает с полным снимком карты в
памяти и публикует его одной кнопкой.

- **Загрузка**: `map.get` + `map.getTerrains` один раз на открытие страницы.
- **Правки**: узлы, размещения, области, ленты, рёбра, варианты, поля карты —
  только в локальном снимке. Запросов нет.
- **Dirty**: снимок сравнивается с загруженным по ссылке-эталону; кнопка
  «Сохранить» активна только при изменениях.
- **Публикация**: `map.save` с `expectedVersion` из загруженного снимка. Успех —
  клиент принимает ответный снимок как новый эталон, счётчик `version`
  обновляется, `dirty` сбрасывается.
- **Уход со страницы**: `beforeunload` и router-guard при `dirty`.
- **Восстановление после F5**: в этой итерации нет; `localStorage` — следующая.

### Конфликт версий

`map.save` вернул `MAP_VERSION_CONFLICT` — показываем диалог с тремя исходами:

1. **Перезаписать** — повторный `map.save` с `force = true`.
2. **Продолжить редактирование** — черновик остаётся как есть; пользователь сам
   решает, что делать дальше.
3. **Сохранить копией** — `map.save` без `id`, имя «‹название› (копия)»,
   видимость `private`. Черновик уходит в новую карту, исходная не трогается.

Диалог показывает `updatedAt` и `updatedBy` из `details`, чтобы было видно, что
именно изменилось.

## Инструменты

| инструмент | действие |
|---|---|
| Выбор и панорама | клик — выбор; drag объекта — перенос целиком; пустое место — панорама; колесо — зум |
| Узел | клик — новый узел; drag существующего — перенос |
| Ребро | клик по двум узлам — ребро; двойной клик по ребру — точка пути; вершины пути тянутся |
| Полигон | клики по вершинам, двойной клик/Enter — замкнуть; вершины тянутся, двойной клик по сегменту — вставить |
| Прямоугольник | два клика — область-прямоугольник (дома, склады) |
| Лента | клики по осевой линии; Enter — завершить; вершины, ручки Безье и ширина по точкам |
| Линейка | клики по произвольным точкам; расстояние по масштабу |
| Калибровка | отрезок по шкале + метры → `millimetersPerPixel` |

У выбранной ленты видны вершины, ручки Безье и ромб ширины у каждой точки.
Новая лента сразу сглажена; «Угол» возвращает прямые сегменты. У активной
вершины ручки Безье показываются направляющими-заглушками, даже если кривизны
ещё нет: потяните за них, `Alt` разрывает симметрию. «Сгладить» расставляет
ручки автоматически. Ромб ширины стоит за краем полосы и не прыгает при
захвате; точную ширину можно ввести числом в панели объекта — для одной точки
или сразу для всех. «Ответвить» создаёт новую ленту из выбранной точки с тем же
террейном и шириной.

Края ленты строятся с ограничением митры: на острых поворотах полоса не даёт
игл и самопересечений. Прямоугольник и лента — новые: полигоном дом рисовать
долго, а реку — почти невозможно.

## Компоненты

- `MapCanvas.vue` — единственный canvas: подложка, ландшафт, объекты, ленты,
  рёбра, узлы, маршрут, черновики, выделение.
- `MapToolbar.vue` — режим, инструмент, вариант, подложка, undo/redo, зум, fit,
  «Сохранить», индикатор изменений, справка.
- `MapSidebar.vue` — узлы, объекты, ландшафт, ленты, рёбра; фильтр «только
  именованные / только POI», иначе после импорта список распухнет.
- `MapNodeDialog.vue` — узел: POI/waypoint, имя, `shortInfo`, `publicInfo`,
  `gmInfo`, `linkedMapId`, иконка.
- `MapAreaDialog.vue` — область: слой, террейн или вид объекта, метка,
  `blocksMovement`, привязка к POI или создание точки интереса в центроиде.
- `MapLineDialog.vue` — лента: террейн, метка; ширина по точкам задаётся на
  карте, при создании — стартовая.
- `MapEdgeDialog.vue` — ребро: террейн, направленность, расстояние, метка,
  предупреждения о пересечениях.
- `MapVariantDialog.vue` — вариант: label, `fromMinutes`, `sortOrder`, файл,
  масштаб, default.
- `MapRoutePanel.vue` — откуда/куда по любым узлам, расстояние, cost, сброс.
- `MapHelpDialog.vue` — краткая справка по инструментам и клавишам.
- `MapCreateDialog.vue` — имя, описание, видимость.
- `MapSettingsDialog.vue` — правка карты, архив.
- `MapCalibrationDialog.vue` — метры по откалиброванному отрезку.
- `MapConflictDialog.vue` — перезаписать / продолжить / копия.
- `MapWarningsDialog.vue` — предупреждения после публикации.

## Сервисы

- `MapViewportService` — мир ↔ экран, zoom, pan, fit; вид передаётся значением.
- `MapGeometryService` — длина полилинии, площадь/центроид, point-in-polygon,
  расстояние до отрезка, пересечение отрезков, попадание в ленту; разворот
  Безье в полилинию, касательная/нормаль, деление кубического сегмента.
- `MapHitTestService` — узел → объект → лента → ребро; допуск ленты = `width / 2`.
- `MapRouteGraph` — чистый Dijkstra по черновику (зеркало серверного).
- `MapApi` — шесть действий `map.*`; `MapApiError` с кодами и русскими
  подсказками.

## Композаблы

- `useMapList` — страница, поиск, архив, создание карты (через `map.save`).
- `useMapDetail` — загрузка снимка, справочник террейнов, выбор варианта.
- `useMapDraft` — копия снимка, правки, `dirty`, публикация, конфликт, копия;
  история undo/redo и транзакции drag.
- `useMapEditor` — вид, инструмент, черновики полигона/ленты/ребра, линейка,
  калибровка, перетаскивание объектов, вершин, ручек и ширины. Расчёты
  делегируются сервисам, рисование — `MapCanvas`.
- `useMapRoute` — маршрут по черновику, локальный расчёт.

Логика — в классах `Service/` и композаблах, не в `.vue`. Canvas — единственное
место рисования.

## Данные

DTO повторяют JSON `map.get`: `MapDetail`, `MapSummary`, `MapVariant`, `MapNode`,
`MapNodePlacement`, `MapArea`, `MapAreaShape`, `MapLine`, `MapEdge`, `MapTerrain`,
`MapRoute`, `MapPoint`.

- `MapVariant` больше не несёт `version`.
- `MapArea` получает `layer`, `blocksMovement`; `kind` — только для объектов.
- `MapLine` — `variantId`, `terrainCode`, `points`, `widths`, `handles`, `label`,
  `isPresent`. `handles` — in/out-смещения Безье по точкам.
- `MapEdge.path` — всегда массив; `[]` означает прямую между узлами.
- `MapDetail.canEdit` управляет видимостью `publicInfo`/`gmInfo` и инструментами
  редактора. `shortInfo` видят все.

## Поведение

- Подложка грузится по `FileApi.getViewUrl(publicId)`; при ошибке — заглушка.
  Размеры мира берутся из `FileRecord`: после выбора файла черновик сразу
  получает `width`/`height`, поэтому картинка не растягивается, а вьюпорт
  подстраивается под неё. Запасной размер — только если файл их не отдал.
- Координаты — пиксели подложки, целые. Точка прижимается к границам
  `width × height` варианта: клик или перетаскивание за краем ставит её ровно на
  край, а объект целиком останавливается, когда до края доходит любая его точка.
  Ручки Безье и ширина могут выходить за край — это не координаты объекта.
  При смене варианта — свои размещения, формы, ленты и рёбра.
- Новый узел создаётся в текущем варианте: узел + размещение в одном снимке.
- Новый объект/ландшафт: полигон или прямоугольник + связь с вариантом.
- Лента живёт только в текущем варианте; ширина в пикселях, по точке; кривизна —
  ручки Безье, ветвление — отдельные ленты из общей точки.
- Ребро создаётся по двум узлам; террейн по умолчанию `road`; путь правится
  вершинами, `[]` — прямая. Если у варианта нет масштаба, ребро требует
  расстояние в метрах — иначе публикация не пройдёт валидацию.
- Пересечение ребра с блокером — предупреждение, не ошибка; автор подтверждает.
- Маршрут в режиме редактора считается локально по черновику по любым узлам,
  включая waypoint-ы; линейка меряет произвольные точки по масштабу.
- Объект может создать точку интереса в центроиде; информация живёт на узле.
- Ошибки API показываются русскими подсказками по коду; для `MAP_INVALID`
  добавляется путь к полю (`lines[0].points — недопустимая точка`).
- Ошибка публикации не сбрасывает черновик: «Повторить» есть только у ошибки
  загрузки, у ошибки сохранения — «Скрыть». Перед перезагрузкой карты с
  несохранёнными правками спрашивается подтверждение.

## Тесты

- `MapViewportService` — зум вокруг курсора, fit, screen↔world, границы.
- `MapGeometryService` — длина полилинии, point-in-polygon, площадь, расстояние
  до отрезка, попадание в ленту, пересечение отрезков, разворот Безье, деление
  кубического сегмента.
- `MapHitTestService` — приоритет узла над объектом, лентой и ребром; попадание
  по изогнутой ленте.
- `MapRouteGraph` — те же случаи, что у серверного: параллельные рёбра,
  направленное, блокер, нет пути.
- `MapApi` — тело `map.save`, `expectedVersion`, `force`, конфликт, `MapApiError`.
- `useMapDraft` — `dirty`, принятие ответного снимка, копия при конфликте,
  undo/redo, сохранение ширин и ручек.

## Вне среза

- SVG-парсер и массовый импорт домов.
- Древовидная структура веток ленты; ветки — отдельные ленты из общей точки.
- `localStorage`-черновик.
- Игровое раскрытие (`GameWorld`).
- Совместное редактирование, SSE.
- Мобильные жесты сверх pan/zoom.
