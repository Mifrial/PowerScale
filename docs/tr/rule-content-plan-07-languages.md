# C2 — план: языки, письменность, народность, книжный червь

**Статус:** `DRAFT`, 2026-09-15.  
**Родитель:** [`rule-content-roadmap.md`](rule-content-roadmap.md).  
**Очередь:** [`rule-content-queue.md`](rule-content-queue.md).  
**Карточки:** `vladenie-yazykom`, `pismennost`, `pravilnoe-proiznoshenie`, `chtenie-po-gubam`, `gramotnost`, `bookworm`; заглушка `language-native` **убрать**.  
**Канон знаний (не переписывать):** [`rule-content-plan-04-knowledge.md`](rule-content-plan-04-knowledge.md) — близость режет уровень, не плодит экземпляр.

Game-проверки «понял речь», генерация имён, PHP-таблицы `nations` — **не этот срез**.

## 0. Зачем не список «родственные»

Языки будут добавляться. Если у каждого языка массив `related_codes`, каждый новый язык требует правок **уже существующих** карт. Это не масштабируется.

Родство считается из **дерева**, которое пишется только на **новой** карточке: один `parent_code`. Старые карты не трогаем.

Аналог знаний: близость вида — общий keyword типа тела, не таблица пар. Здесь близость — общий узел дерева, не hops «до 3 прыжков» по живым языкам (иначе вся семья слипается в «почти родной»).

## 1. Три справочника

| Тип правила | Роль |
| --- | --- |
| `language` | Дерево: **стоки** (семья/ветка, не изучаются) и **языки** (покупаются) |
| `script` | Письменность: фонетика или иероглифы |
| `ethnicity` | Народность: расы, языки, какие пары язык+письменность у народа живые |

Кастом на листе — код **или** свой текст (как слот знания). Свой текст **не** входит в дерево и **не** шарит родство.

Заглушку `language-native` удалить. Родной язык — поле листа, не карта каталога.

### 1.1 Дерево языков (`LanguageSpec`)

```text
role: 'stock' | 'language'     // stock нельзя купить как владение
parent_code: string | null     // один родитель; только на этой карте
script_codes: string[]         // только role: language; карты письменности (не перечень букв/иероглифов)
```

- Корень семьи: `role: stock`, `parent_code: null` (напр. «Локс»).
- Ветка-кластер нескольких живых языков: stock («Ишхет», «Казар»).
- Праязык с живым потомком: `role: language` («Пра-Радос» → Радос, «Сомнарил» → Сомнорил) — иначе его нельзя выучить.
- Прочий язык: `role: language`, родитель — сток или другой язык (диалект).
- Цикл `parent_code` — ошибка валидации.
- Креол с двумя родителями — **не срез**; один родитель.

Добавить язык долины: карточка с `parent_code: ishkhet`. Улай'тиль и Ар'тиль **не** правятся и становятся родственными через Ишхет.

### 1.2 Как считается близость (только `role: language`)

**Ближайший сток** языка — первый предок с `role: stock` (у диалекта это сток родителя-языка).

| Отношение A и B | Эффект к чужому языку |
| --- | --- |
| Это один код | точный экземпляр: **L** |
| Один — предок другого среди языков (диалект ↔ язык) | **родственные:** L − 1 |
| Один и тот же ближайший сток (ветка: Ишхет → Улай'тиль, Шыим'тиль, Чур'тиль, Ар'тиль **и** их диалекты) | **родственные:** L − 1 |
| Один **корень** дерева, ближайшие стоки разные (Радос/Пра-Радос → Локс, Улай'тиль → Ишхет) | **группа:** L − 2 |
| Нет общего корня / нет parent / кастом-текст | **0** |

Не «сиблинги только если прямой родитель один»: иначе диалект Улай'тиль и Ар'тиль оказывались бы группой, хотя оба под Ишхетом. Не hops 2–3 по любым узлам.

Язык без `parent_code` — изолят: нет семьи. Диалект изолята (`parent` = этот язык) всё равно **родственник** предку по строке «диалект ↔ язык», даже если ближайшего стока нет.

Чтобы семья давала −2, а не −1, нужны **ветки-стоки** под корнем. Языки, висящие прямо на корневом стоке, все родственны.

Уровень режется в **пол**: `max(0, L − n)`. Берётся **max** по экземплярам на листе. Фантом «орочий 1, потому что родственник» **не** покупается. Один код языка — **один** экземпляр `vladenie-yazykom` (как слот знания).

Владение языком **не** копирует полный L на диалект: Улай'тиль 2 даёт восточному улайскому **1**, не 2.

```text
эффективный_устный(X) = max(
  L точного X,
  L−1 родственного экземпляра,
  L−2 экземпляра той же семьи
)
```

**Следствие:** родной язык **2** даёт родственникам 1, группе **0**. Радос 2 не даёт Улай'тиль «через Локс». Клапан сознательный: семья начинает работать с L = 3 или с покупки второго языка. Не поднимать авто-родной до 3 из‑за этого.

**Каталог (мок)** — все `parent_code` только на своей карте. Коды: `locx`, `pra-rados`, `rados`, `ishkhet`, `ulay-til`, `shyim-til`, `chur-til`, `ar-til`, `dargr`, `gargat`, `kami`, `kalami`, `linmaril`, `somnaril`, `somnoril`, `pesh`, `kazar`, `yaryn`, `khas`, `aynyr`.

```text
локс (stock)
  пра-радос (language)
    радос (language)
  ишхет (stock)
    улай'тиль, шыим'тиль, чур'тиль, ар'тиль (language)
даргр (stock)
  гаргат (language)
ками (stock)
  калами (language)
линмарил (stock)
  сомнарил (language)
    сомнорил (language)
пеш (stock)
  казар (stock)
    ярын, хас, айныр (language)
```

Ближайший сток: радос/пра-радос → локс; улай'тиль → ишхет; сомнорил/сомнарил → линмарил; ярын → казар.  
Радос **2** → пра-радос **1**, языки долины **0**; Радос **3** → улай'тиль **1**. Улай'тиль **2** → шыим'тиль **1**. Сомнорил **2** → сомнарил **1**.

### 1.3 Письменность (`ScriptSpec`)

```text
kind: 'alphabetic' | 'logographic'   // список расширяемый
```

Карта `script` — вид (`kind`) плюс общий `description`. Перечень букв и иероглифов в спеку **не** кладём.

Навык `pismennost`: **экземпляр письменности**, не языка.

| kind | Лестница ОР |
| --- | --- |
| alphabetic | один уровень, **1** |
| logographic | **1 / 1 / 1** |

Один экземпляр «кириллица» покрывает все языки с этой письменностью в `script_codes`.

Читать/писать язык X = `эффективный_устный(X) ≥ 1` **и** есть экземпляр письменности из `script_codes` X. Родство речи письменность **не** выдаёт.

`pismennost` — **не** ребёнок `vladenie-yazykom`: иначе нельзя купить знаки без речи (червь). Навык независимый, `multiple` + якорь карты `script`. Лестница ОР **с kind выбранной карты** (не одна статическая `levels_cost` на все письменности): фонетика кап 1, иероглифы 1-1-1. `DOMAIN_REF_RULE_TYPES['script'] = ['script']`.

Два экземпляра письменности, если нужны и алфавит, и иероглифы; речь — один `vladenie-yazykom`.

`pravilnoe-proiznoshenie`, `chtenie-po-gubam`, `gramotnost` — дети языка, якорь **тот же код языка**, что у **купленного** экземпляра речи. Эффективный уровень родственника (улай'тиль 2 → ар'тиль 1) **не** открывает детей на ар'тиль.

Кастом-письменность (свой текст, не карта `script`): как `alphabetic`, один уровень 1. Без `kind` иероглифов.

`gramotnost` и 3-й уровень владения: в контексте языка X есть экземпляр `pismennost`, чей код ∈ `script_codes` X. Это не `has_ability pismennost` без якоря (любая кириллица закрывала бы эльфийский) и не `domain_ref` письменности = языка.

### 1.4 Народность (`EthnicitySpec`)

```text
role: 'stock' | 'people'     // stock не выбирается на листе
parent_code: string | null
race_codes: string[]         // пока пусто
language_codes: string[]     // на каких языках говорят (в т.ч. без письма)
usages: { language_code: string, script_codes: string[] }[]
```

Язык в `usages` обязан быть в `language_codes`. Письмо в `usages` — подмножество `script_codes` языка. Раса ↔ народность — м-к-м. Нет народностей с этой расой — только своя строка.

**Не народ:** «Раден», «Эльфийское Всенародное Содружество» — стоки-кластеры.

**Каталог (мок), коды уникальны относительно языков:**

```text
раден (stock)
  СРИ, БРИ, РС (people) — язык радос, быт: раденский алфавит
Эльфийское Всенародное Содружество (stock)
  форнийцы (people) — сомнорил
улай, шыим, чур — свой «тиль» + ар'тиль (ар'тиль не народ)
грогхар — гаргат
оула — калами
ярын / хас / айныр — коды yaryn-folk / khas-folk / aynyr-folk
```

Алиерцы, дюарийцы, когиры, анеиты, ахтары и прочие культуры Радена — **не этот срез**.

Имя с народности — **не срез**.

## 2. Лист

На `Character` / версии: `ethnicityCode` **или** `ethnicityText`; `nativeLanguageCode` **или** `nativeLanguageText` (как слот знания). Не карта `language-native`.

При выборе расы: народность из тех, у кого раса в `race_codes`, **или** своя строка. Родной язык — из `language_codes` народности (эти сверху в селекте) или свой.

Автоэкземпляр `vladenie-yazykom` **уровень 2** на родной язык (грант/`permanent`, смена родного **переносит** этот экземпляр, не плодит второй). Стартовую письменность **не** выдавать автоматом (только ОР или книжный червь).

Селект владения: `type === 'language' && spec.role === 'language'` — стоки не показывать (`domainOptionsOf`).

Доп. язык: селект speakable `language`; в карточке — народности, где он есть, и `script_codes` / виды письменностей.

Кастом язык/народность/письменность — текст без дерева.

`vladenie-yazykom` остаётся `multiple` + якорь **кода языка** (не сток). Улучшения — тот же код языка, что у родителя-экземпляра.

## 3. Книжный червь

Канон плана-04: бесплатный экземпляр `znanie` **любого** типа (слоты заполняет игрок) **или** письменность. Не хирургия, не речь языка.

`magic_study` завязан на путь волшебства — **не** брать как есть. Нужен грант «выбранный навык + якорь за 0 ОР»: либо новый экземпляр `znanie` (тип + слоты), либо `pismennost` на выбранный `script`. Фонетика — уровень 1; иероглифы — только 1-й уровень 1-1-1. Не речь, не грамотность, не хирургия. Старый `contentNote` про грамотность у червя — выкинуть.

## 4. Каталог (миграция)

## 5. Срез реализации (лист, не Game речь)

1. DTO: расширить `LanguageSpec`; новые `ScriptSpec`, `EthnicitySpec`; типы в `RuleType`.
2. Редакторы карт: parent (без цикла), role, script_codes; письменность kind; народность usages.
3. Сервис близости (unit): точный / диалект / тот же ближайший сток / тот же корень −2 / 0; кастом = 0.
4. Лист: народность, родной язык, авто-2, покупка языка и письменности, дети на том же языке.
5. Книжный червь: выбор знания или письменности за 0 ОР.
6. **Канон:** письменность покупается **без** речи (знаки без понимания). Применение к языку (читать/писать, грамотность, 3-й уровень владения) требует речь и подходящий script. Не писать в требованиях покупки `pismennost` «нужна речь».

Не входят: генерация имён; Game-проверка понимания; PHP persist народности; чувства/освещение; креолы с двумя родителями.

## 6. Тестовый минимум

- Новый язык с родителем `ishkhet`: улай'тиль родственен ему **без** правок его карты.
- Диалект улай'тиль и ар'тиль: тот же ближайший сток → родственники, не группа.
- Радос 2 → улай'тиль эфф. 0; улай'тиль 2 → шыим'тиль эфф. 1.
- Радос 3 → улай'тиль эфф. 1.
- Диалект с родителем-языком: L−1 к родителю.
- Кастом-текст: эфф. только точный, не семья.
- Кириллица 1 + речь языка A и B, оба с этой письменностью → писать оба; язык C без этой письменности — нет.
- Червь: либо `znanie` со слотами, либо script; не `vladenie-yazykom`.
- Дети языка: ар'тиль эфф. 1 от улай'тиль 2 **не** даёт купить `gramotnost` на ар'тиль.
- Изолят без стока + его диалект: родственники, семьи нет.
