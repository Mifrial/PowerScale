# План M21 — сопротивление магии против эффектов заклинаний

**Реализация:** ~PHP~, ~VUE~, контент ревизии 66.

**Опираться на:** ~PHP~ (`SpellSpec`, `SpellSpecs`, `GameSpellCastCheck`,

**Родитель:** [`spell-real-roadmap.md`](spell-real-roadmap.md), M20 и

## 1. Задача

«Сопротивление магии» уже режет арканный урон как обычное сопротивление, но
повышало Сложность сотворения по признаку `targeting: entity`. Из-за этого
касательные эффекты Ноломансии, у которых нет ни урона, ни цели заклинания,
не встречали сопротивления вообще. При этом «Разряд» тоже касание, и его
сопротивление магии не должно касаться.

Нужен один явный признак: **эффект заклинания является магическим
воздействием на цель**. Он не должен выводиться ни из `targeting`, ни из
типа урона.

## 2. Решения

1. **Единственный критерий повышения Сложности — `spell.resisted_by_magic`.**
   `targeting: entity` сам по себе больше не включает сопротивление. Все
   целевые карточки получают флаг в контенте; фронтенд-валидация требует его
   у `targeting: entity`.
2. **Арканный урон не добавляет Сложность сам по себе.** Сопротивление магии
   уменьшает арканный урон обычным сопротивлением; повышение Сложности
   включается только флагом.
3. **Цель сопротивления — `prepared->target ?? prepared->damageTarget`.**
   У касательных заклинаний цели заклинания нет, поэтому используется цель
   касания. У целевых заклинаний — выбранная цель.
4. **Против себя сопротивление не работает.** В текущей версии правил каст
   на себя не получает собственное сопротивление магии; это правило
   реализовано в `GameSpellCastCheck`.
5. **Пробитие сопротивления учитывается как раньше.** `resistancePenetration`
   вычитается из сопротивления цели, расчёт остаётся в
   `GameSpellMagicResistance`.
6. **Флаг только на заклинании.** Эффекты (`spell.effects[]`) пока флага не
   имеют: для каста достаточно свойства карточки.

## 3. Срезы

### 21.1. Форма и движок

- `SpellSpec::isResistedByMagic()` и разбор `resisted_by_magic` в
  `SpellSpecs`;
- `GameSpellCastCheck::difficultyResistance` читает только флаг, выбирает
  цель заклинания или касания и пропускает самокаст;
- арканный урон по-прежнему считается через `GameStrikeDefense` и
  `GameSpellCastDamage`, без изменений.

### 21.2. Фронтенд

- `SpellSpec.resisted_by_magic` в TypeScript;
- `SpellCastDifficultyService` включает сопротивление по флагу, а не по
  `hasTarget`;
- `SpellCastService` (путь без Контроля) — так же;
- `SpellCastDialog` берёт сопротивление с цели касания, если флаг стоит;
- `SpellEditor` — чекбокс «Сопротивление магии цели повышает Сложность»;
- `RuleValidationService` — тип флага и требование флага для
  `targeting: entity`;
- `mockSpellImport` помечает целевые заклинания.

### 21.3. Контент и проверки

- `tools/rule-migrate-66.php`: `resisted_by_magic: true` у 16 карт
  Ноломансии и у `targeting: entity` (`lightning-strike`), ревизия 66;
- unit: `SpellSpecsTest` — разбор флага и значение по умолчанию;
- mysql: `GameStrikeMysqlTest` — целевое заклинание с сопротивлением,
  касательное состояние с сопротивлением, «Разряд» без сопротивления;
- vitest: сложность по флагу, отсутствие сопротивления без флага,
  валидация целевого заклинания.
