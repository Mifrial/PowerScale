# Концепция Ноломансии 01 — школа эффектов и касаний

**Статус:** ~СДЕЛАНО~, 2026-11-16. Концепция и первая контентная пачка

## 1. Задача

Ноломансия в сыром документе — не список заклинаний, а конструктор из трёх
составляющих:

```text
Эффект (что делает) + Переносчик (как доставляется) + Источник (откуда берётся)
```

База даёт один переносчик — **касание** — и один источник — **создание**.
Остальные переносчики и источники открываются навыками. При этом эффекты
описаны как самостоятельные карточки со своей Стоимостью, Созданием,
Сложностью и Действием.

Задача первой пачки — сохранить эту свободу, но не превращать её в
комбинаторный набор карточек и уложить в текущую модель `spell` + улучшения
каста.

## 2. Что есть в источнике

- **16 эффектов** — от «Слезоточивости» до «Ускоренного обмена веществ».
  У каждого своя цена, время создания, сложность и длительность.
- **Эффект** — главная карточка; именно её изучают.
- **Переносчик**: касание (база) и дистанция (навык). В тексте упомянуты
  также зональность и передача через предметы.
- **Источник**: создание (база) и закрепление в организме с производными
  «Заразность», «Закрепление магии», «Инкубационный период».
- **Улучшения** эффектов: «Нестерпимый зуд», «Неудобная зона», «Резкая боль»,
  «Наружу», «Слабоумие», «Частичный паралич», «Зональное разложение»,
  «Тотальное разложение».
- **Навыки школы**: «Болезнетворчество» (вход), «Опытный ноломант»,
  «Контроль нервов», «Разложение нервов», «Преобразование нервов».
- **«Потоп»** — не отдельный эффект, а правило объединения насморка и
  слезоточивости в одно заклинание.

## 3. Почему конструктор не переносится один в один

В текущей модели заклинание — одна карточка `spell`, а его изменение на
конкретном касте — улучшение (`spell_upgrade`), выбранное в диалоге. Если
выгружать каждую комбинацию «эффект × переносчик × источник» отдельной
карточкой, каталог быстро станет нечитаемым, а изучение — непредсказуемым:
игрок покупает один и тот же эффект по несколько раз.

Поэтому комбинаторную часть надо оставить в данных навыков, а не в карточках
заклинаний.

## 4. Целевая модель

### 4.1. Одна карточка — один эффект

Карточка `spell` описывает **только эффект**. Переносчик «касание» и источник
«создание» уже вшиты в её базовую спеку:

- `targeting: "none"` + `hit_resolution: { "type": "attack" }` — доставка
  ударом касания. Цель касания приходит из боевого выбора и становится
  `damageTarget`; отдельный `targeting: "entity"` здесь не нужен и дублировал
  бы цель.
- соматический компонент «Касание цели»;
- ресурсный компонент «Сотворение» с временем из карточки;
- длительность из карточки.

Так любая карточка Ноломансии по умолчанию является заклинанием касания,
создаваемым в момент каста.

### 4.2. Переносчик и источник — навыки каста

Всё, что в источнике меняет способ доставки или источник, становится
**навыком, выбираемым при касте**, а не отдельным заклинанием:

- «Дистанция» — каст на расстоянии `x` ипари с повышением сложности на `x`;
- будущие «Зона», «Через предмет» — тем же способом;
- «Закрепление в организме», «Заразность», «Закрепление магии» — источник
  каста, а не другая карточка эффекта.

Навык должен уметь ограничиваться школой (признак `nolomancy`), а не только
`parent_ability_code` конкретного заклинания: «Дистанция» применяется к любому
эффекту Ноломансии. Механика такого ограничения — отдельный срез (см. §8).

### 4.3. «Потоп» — не карточка-заклинание

В первой пачке «Потоп» остаётся текстом. Позже это либо улучшение каста
«объединить два изученных эффекта в один каст», либо отдельное правило
комбинирования. Дублировать насморк и слезоточивость третьей карточкой нельзя.

## 5. Перевод чисел из настольной версии

В источнике задана фиксированная «Сложность» заклинания. В текущей модели
Сложность сотворения считается из требований Мощи и Контроля:

```text
Сложность = база {3|0} + нехватка Мощи + нехватка Контроля − превышение
```

Поэтому сырая Сложность переводится в **требуемую Мощь**, а требуемый Контроль
пока ставится таким же. Дальше Контроль правится вручную по замыслу карточки.

| Сырая Сложность | Требуемая Мощь и Контроль |
| --- | --- |
| `{1|-1}` (1↓) | `{3|-1}` |
| `{2|-1}`, `{3|-1}`, `{1|0}` (2↓, 3↓, 1) | `{4|-1}` |
| `{4|-1}`, `{5|-1}`, `{2|0}` (4↓, 5↓, 2) | `{5|-1}` |
| `{3|0}` (3) | `{3|0}` |
| `{3|1}` (3↑) | `{3|1}` |
| `х↑` | параметр `x` |

Решения:

1. Сырая Сложность **не хранится** отдельным полем `difficulty`. Если позже
   понадобится точное значение, это будет отдельный срез с модификатором
   Сложности, а не тихая подмена текущей формулы.
2. `х↑` — упрощение настольной записи. В каждой карточке `x` разбирается отдельно.
   Для «Поглотителей магии» `x` — это и есть величина поглощения, поэтому
   используется обычный параметр `x`, без дополнительного размера.
3. Требуемая Мощь и Контроль в первой пачке совпадают. Это осознанно: школа
   должна быть требовательнее к Контролю, но конкретные значения будут
   выправлены вручную после первых игровых проверок.

## 6. Создание и длительность

| Источник | Форма Rule |
| --- | --- |
| Создание `3ОД`, `5ОД` | `action_components`: ресурс `action-points` |
| Создание `1 ход` | `amount: { "type": "turn", "count": 1 }` |
| Создание `10 минут` | `amount: { "type": "turn", "count": 10 }` |
| Действие `мгновенно` | `duration: { "type": "instant" }` |
| Действие `1 ход` | `duration: { "type": "lingering", "limit": { "value": 1, "unit": "turn" } }` |
| Действие `5 ходов` | `lingering`, `5 turn` |
| Действие `1 минута` | `lingering`, `1 minute` |
| Действие `30 минут` | `lingering`, `30 minute` |
| Действие `1 день` | `lingering`, `24 hour` |

Сейчас Game принимает `instant`, `sustained` и `lingering`. Поэтому:

- мгновенные карточки выгружаются без оговорки по длительности;
- `lingering`-карточки получают срок в собственных ходах цели; эффект
  накладывается строкой `game_active_effect` и тикает в конце хода цели
  (M19);
- поддержание (`sustained`) для Ноломансии не используется: её эффекты
  существуют по таймеру, а не за счёт поддержания.

1 минута = 10 ходов — то же соглашение, что в M16/M17.

### 6.1. Контейнер и тик

Лист не хранит срок эффекта. Строка `game_active_effect` — источник истины:

- `source_type` (`spell` сейчас), `source_rule_code`, `strength`, `context` —
  без жёсткой привязки к заклинаниям;
- `target_kind`/`target_id` — цель;
- `duration_unit`, `turns_total`, `turns_left` — срок;
- `started_round`/`started_participant` — пропуск первого тика при касте на
  себя.

Состояние на листе остаётся вычислительным слоем: когда эффект по смыслу
станет состоянием, проекция добавит временную строку на чтении, как `sense`
в M16. Записывать эффект прямо в лист нельзя: тогда срок, конец боя и
рассинхронизация версий становятся отдельной обязанностью листа.

Тик — конец собственного хода цели. «1 ход» = 1 тик, минута = 10, час = 600.
Эффект-специфичный тик идёт до уменьшения срока: последний ход тоже должен
отработать.

## 7. Эффекты

В первой пачке **нет `spell.effects`**. Эффект Ноломансии — это не мгновенное
действие, а наложенное состояние на цель:

- «Слепота», «Глухота», «Паралич», «Слабость», «Неуклюжесть» меняют лист
  цели;
- «Чесотка», «Тошнота», «Боль» требуют проверки цели;
- «Рассеянность» и «Разложение» работают по ходам;
- «Поглотители магии» меняют сопротивление и добавляют поглощение;
- «Ускоренный обмен» меняет отдых и расход ресурсов.

Для всего этого нужны три вещи:

1. хранение цели активного эффекта — сделано в M19
   (`game_active_effect.target_kind/target_id`);
2. длительность `lingering` и её тик — сделано в M19;
3. форма эффекта «состояние/проверка/изменение листа» и её снятие — следующий
   срез.

В первой пачке эффект живёт **в описании**, а карточка помечена `needs_work`.
После M19 срок и цель работают. M20 добавляет форму
`spell.effects[].type = state`: состояние цели читается из строки
`game_active_effect` и влияет на лист без записи срока в лист. Срез 20.1
закрыт на «Слепоте живого» (`blindness`); в 20.2 состояние получило эффект
`sense_status` и действительно лишает цель зрения, добавились `deafness`
(лишает слуха) и `clumsiness` (−3 Восприятию, помеха Ловкости, Реакции и
попаданию). Остальные карточки остаются `needs_work`, пока их эффект не
реализован.

Сопротивление магии — главная слабость школы. Все 16 карт получают
`spell.resisted_by_magic: true`: сопротивление магии цели повышает Сложность
сотворения и на касание, и на целевой каст. Арканный урон при этом режется
сопротивлением как обычное сопротивление, без автоматического повышения
Сложности. Каст на себя собственное сопротивление не учитывает — это правило
текущей версии правил. «Разряд» флага не получает, поэтому его сопротивление
магии не касается.

## 8. Улучшения: порядок реализации

1. **Дальность** — сделано в M22 как «Проклятие взглядом»: улучшение
   любого касательного заклинания ноломансии, N — предел дальности, мощь
   +N пунктов, контроль +2; фактическое расстояние заявки (размерное
   `distance`, как у удара) не больше N.
   Отдельного переносчика «Дистанция» нет.
2. **Числовые улучшения сложности**: «Нестерпимый зуд», «Резкая боль»,
   «Наружу», «Слабоумие», «Тотальное разложение». Им нужен модификатор
   Сложности каста и проверки эффекта.
3. **Позиционные и описательные**: «Неудобная зона», «Частичный паралич»,
   «Зональное разложение». Сначала — текст и ручное решение мастера, потом
   механика.
4. **Преимущества проверки** — сделано в M22: «Опытный ноломант» (`+1`) и
   «Контроль нервов» (`+2` для нервной системы) с фильтром по признакам и
   одним источником преимущества `mastery`.
5. **Источники**: «Закрепление в организме», «Заразность», «Закрепление
   магии», «Инкубационный период». Это отдельная модель источника каста,
   а не ещё одно заклинание.
6. **«Потоп»** — комбинирование двух эффектов в один каст.
7. **«Разложение нервов» / «Преобразование нервов»** — постоянные и снимаемые
   штрафы; после модели состояний и длительностей.

  пачки;

## 10. Что не входит в пачку

- источники «Закрепление…», «Заразность», «Инкубационный период» — отброшены
  как отдельная модель;
- «Болезнетворчество» — конструктор из трёх составляющих отменён: эффект
  остаётся полноценным заклинанием с касанием и созданием;
- «Потоп» — объединение двух эффектов в один каст;
- намеренное снятие постоянных состояний «Преобразованием нервов»;
- улучшения эффектов;
- runtime проверок цели;
- цена навыков-переносчиков.

Навыки школы (Опытный ноломант, Контроль нервов, Проклятие взглядом,
Разложение и Преобразование нервов) выгружены в ревизии 68 — см. M22.

Это следующая пачка. Её порядок — §8.

## 11. Открытые решения

1. Точные значения требуемого Контроля по карточкам — правятся вручную
   после первой игровой проверки.
2. Форма улучшения «Дистанция»: шаги `distance`/`difficulty` в
   `spell_upgrade` против отдельного поля переносчика.
3. Ограничение улучшения школой: `keyword_ref`/`school` в `spell_upgrade`
   против `domain_ref` пути.
4. Модель цели активного эффекта — решено в M19: отдельная строка
   `game_active_effect` с целью, а не колонка в `game_active_spell`.
5. Тик `lingering` и снятие эффекта сделаны в M19; состояние на лист цели —
   в M20.1. Проверки цели при наложении и по ходам — следующие срезы.
6. Форма требования «опыт признака» (`10 опыта ноломансии`).
7. Цена и способ покупки навыков-переносчиков и источников.
