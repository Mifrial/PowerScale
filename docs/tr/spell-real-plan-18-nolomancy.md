## 1. Границы

Входит:

- черновая выгрузка HTML в Markdown;
- концепция школы: эффект — карточка, переносчик и источник — навыки каста;
- первая пачка из 16 эффектов с корректным описанием, созданием,
  длительностью, ценой, требованиями и признаками;
- секция каталога «Заклинания → Ноломансия».

Не входит:

- runtime эффектов, проверок цели и состояний;
- runtime длительности `lingering`;
- навыки школы, переносчики, источник и улучшения эффектов;
- «Потоп» и комбинирование эффектов;
- правки Vue.

Все 16 карточек получают `needs_work`: эффект не реализован. Для карточек с
`lingering` в комментарии отдельно указано, что длительность пока не
поддержана Game.

## 2. Решения

1. **Касание и создание — база карточки.** `targeting: none`,
   `hit_resolution: attack`, соматика «Касание цели», ресурсный компонент
   «Сотворение». Цель касания приходит из боевого выбора.
2. **Переносчик и источник — навыки каста.** «Дистанция» и будущие
   «Закрепление…» не становятся отдельными заклинаниями. Ограничение по школе
   — признак `nolomancy`, форма улучшения — следующий срез.
3. **Сырая Сложность → требуемая Мощь.** `1↓ → {3|-1}`, `1 → {4|-1}`,
   `3 → {3|0}`, `3↑ → {3|1}`, `х↑ → параметр x`. Требуемый Контроль пока
   равен требуемой Мощи, дальше правится вручную.
4. **Длительность.** `мгновенно → instant`; `1/5 ходов, минуты, день →
   lingering` с лимитом. Поддержание не используется.
5. **Эффект — в описании.** `spell.effects` не заполняется: у школы нет
   примитива состояния/проверки цели, а молчаливая пустышка недопустима.
6. **Опциональное требование по опыту** не моделируется; выносится в
   `content_note`.
7. **Коды** — английские, по эффекту: `tearing`, `runny-nose`,
   `living-itch`, … (полный список — в концепции §9).
