## 0. Что уже есть

- Состояние `wound`: `aggregation: independent`, `value` = одно число. Сводка карточки: «4, 1».
- Удар / сотворение / тик DOT: `addCombatState({ value })` — новая запись с силой, без закрытости.
- Конец хода раненого: `BloodLossService.applyTurnWoundBleed` берёт **сумму `value`** всех ран → прирост `blood-loss`. Потом `EndOfTurnDotsService` (яд, горение, …).
- У `wound` в спеке висит `damage_over_time`. В рантайме **уже не стреляет**: `DotTickMathService.advanceDotState` тикает только горение и яд. Двойного контура нет; спеку всё равно почистить (описание канона: кровь, не DOT-удар). Отдельный «ремень skip» в `EndOfTurnDotsService` не нужен.
- `rule-blood-clotting` в каталоге (simple), Game **не** читает.
- Первая помощь / спорая — навыки в каталоге; кнопок перевязки нет; `contentNote` у спорой — «пока не исполняется».
- `CharacterStateValue` уже умеет sidecar у увечья (`maim`). Ране — тот же приём.
- Свободные руки инвентарём не считаются. Процесс/касание — другой контур.
- Суток в боевом Game нет (есть `gameTime` как значение, не тик дня).

Боевая карточка уже толстая: логика раны — **сервис**, UI — дочерний блок строки раны, не простыня в `CombatCardPanel.vue`. Hit/SpellCast не раздувать: общая запись раны через сервис.

## 1. Runtime-канон (узкая выжимка)

У каждой записи `wound`:

```text
сила              = value (≥ 1)
вклад_перевязки
вклад_свёртывания
закрытость        = min(сила, вклад_перевязки + вклад_свёртывания)
закрытость'       = зажата? max(закрытость, 1) : закрытость; затем min(сила)
тик               = сила − закрытость'   (≥ 0)
```

Зажим **не** пишет во вклады. Силу не трогают зажим, перевязка, свёртывание.

Свежая рана: закрытость 0, вклады 0, не зажата, кап перевязки **стоит** (+4), не внутренняя.

**Внутреннюю** нельзя перевязать и нельзя зажать. Свёртывание — можно. Как появляется внутренняя в этом срезе: флаг на записи (мастер на карточке). Удар/сотворение/тик DOT ставят **внешнюю**. Хирургия (сделать обычной) — **не** этот срез.

После любого снижения силы: вклады и итог закрытости **clamp** к новой силе.

### 1.1 Тик крови (конец хода раненого)

Уже есть крючок `applyTurnWoundBleed`.

Порядок на **этом** ходе:

1. Если в ревизии есть `rule-blood-clotting` — по **каждой** ране (и внутренней) проверка свёртывания, затем запись вклада.
2. Δ кровопотери = Σ тик по ранам (не сумма сил).
3. Как сейчас: `applyBloodLossTick`, затем DOT (рана в DOT не участвует).

Проверка свёртывания — карточка **`check-blood-clotting`**: родитель `check-simple` (наследует `rule-6-and-1`), соло, **без** характеристики, `difficulty_input: none`. Пул: **1** куб, грани/эффективность как у свободного куба ревизии (`rollPoolDefaults`), DC `{0|0}` (уже есть `SIMPLE_CHECK_ZERO_DIFFICULTY` / `SimpleCheckRollService`). Гейт исполнения — **`rule-blood-clotting` в ревизии**, не наличие карточки проверки. Нет правила — шаг 1 пропускается.

Из `CheckLaunchDialog` **спрятать** (как `check-injury`): автотик, не ручной запуск. **Без** жетона концентрации и без модалки — как тик крови, не как диалог проверки. Чат: вложение броска на каждую рану.

Успех: вклад свёртывания этой раны **+РУ** (`check.rating`), не выше силы, **без** капа +4.

Порядок «сначала свёртывание, потом Σ тик» — решение посадки. После `replaceCombatState` по ранам — **смержить оверлей в version**, потом `bleedTotal`. Свёртывание гонять **даже если** все раны уже закрыты: `applyBloodLossTick` при Δ≤0 вернёт null, но вклады могли вырасти. Полностью закрытая рана **остаётся** записью (тик 0). `applyTurnWoundBleed` по-прежнему после крови зовёт DOT.

### 1.2 Зажать

Любой, у кого есть свободный «слот руки» этого среза. **2 ОД за рану**. Внутреннюю нельзя. Канон «две руки — две внешние сразу»: одно действие, 1 или 2 раны, ОД = 2 × число. Нет ОД — отказ целиком.

Посадка UI: две раны **открытой карточки** (одной цели). Вторую цель зажать — второе действие (кросс-карточный мультивыбор в этом срезе не делаем). Свои руки на своей карточке — можно (`heldBy` = сам).

Пока держит: закрытость' минимум 1. Отпустил — минимум пропадает, вклады на месте. `heldActive` = `heldBy != null`. Держащий выбыл — **держится, пока не отпустил** (OPEN на автосброс).

Счётчик рук: `heldBy === актор` **во всех оверлеях боя**, максимум 2. Хост передаёт оверлеи. Инвентарь не читаем. Отпустить — 0 ОД.

`heldBy` **сессионный**: в actual / вне боя при commit оверлея — сбросить в `null`. Вклады и `internal`/`aided` оставлять.

### 1.3 Перевязать

Канон «одно действие для всех» = **один тип** перевязки, не пачка. **Одна рана за действие.** Вид не нужен.

`canBandage`: не внутренняя **и** вклад перевязки **вырастет** при этом медике (кап +4 без помощи; с помощью кап снят — растёт до силы). Сумма вкладов уже = сила сама по себе не запрещает, если bandage ещё может вырасти; если bandage уже у своего потолка — отказ, ОД нет.

- +2 к вкладу перевязки этой раны.
- База **8 ОД**.
- У исполнителя `pervaya-pomosch` ≥ 1: **4 ОД** и на **этой** ране `aided`.
- Пока не `aided`: вклад перевязки **≤ 4**.
- `sporaya-perevyazka` только вместе с помощью (как покупка). Если помощь + спорая **и** `woundBandagedOnce` у цели: **2 ОД**. Первая перевязка цели — 8 или 4. Другая цель — снова полная цена.

Внутреннюю перевязать нельзя. Полностью закрытая рана остаётся записью.

### 1.4 Сутки −2 силы

В боевом Game **нет** границы суток. В этом срезе **не** тикать. OPEN: когда появится день/длинный отдых — сила −2 и clamp.

## 2. Границы

Входят:

1. Поле экземпляра раны на `CharacterStateValue` (как `maim`).
2. Сервис: закрытость, тик, кап, зажим, стоимость ОД перевязки, миграция старого `{ value }`.
3. Запись раны с удара/сотворения/DOT-хука через этот сервис (сила = бывший `value`, остальное нули).
4. Конец хода: свёртывание (если правило в ревизии) → Σ тик → текущая кровопотеря.
5. Спеку `wound`: убрать `damage_over_time`; DOT и так не тикает рану.
6. UI: раны снова **тайлы состояний** (сила на тайле). Вклады, внутренняя, зажим, отпустить — **попап тайла**. Перевязать / Зажать — **каталожные automatic-действия** (`perevyazat`, `zazhat`), запуск из «Действий», не блок карточки.
7. Моки персонажей: старые `wound: 4` переживают миграцией.
8. `contentNote` спорой сузить, когда перевязка живая.

Не входят: хирургия и превращение внутренней в обычную; уход / варка / сбор / питание / смертоносные удары; −2/сутки; свободные руки из инвентаря; PHP; pairwise; освещение; книжный червь.

Не плодить отдельные кнопки «Первая помощь» / «Спорая» — только модификаторы перевязки.

## 3. Посадка в данные

На записи состояния `wound`:

```text
value: number                    // сила
wound?: {
  bandage: number                // вклад перевязки
  clotting: number               // вклад свёртывания
  internal: boolean
  aided: boolean                 // кап +4 снят (перевязка с первой помощью)
  heldBy: string | null          // opaque entity key; Character ↛ Game CombatEntityKey
}
```

Нет `wound` — миграция при чтении тика/карточки/записи (не отдельный PHP): сила = `value`, вклады 0, флаги false, `heldBy` null. Любой `addCombatState({ value })` без sidecar тоже через `addWound`.

Sidecar — отдельный DTO `CharacterWound` (один экспорт на файл), поле на `CharacterStateValue` как `poison`/`maim`.

На `GameCombatOverlay` цели:

```text
woundBandagedOnce?: boolean      // уже была перевязка этой цели в бою
```

Только сессия (мок оверлея). PHP не этот срез: живой `GameApi` неизвестные поля может выкинуть — в моке поле копировать при persist. `mergeCombatOverlay` в actual **не** тащит флаг на лист.

Индексы `states` как сейчас. Правка раны — **`replaceCombatState`**, не `setCombatStateValue`. `setNumericState` для `independent` **добавляет голую** `{ value }` — для `wound` не звать; мастер/карточка/удар/каст/DOT/добавление состояния — только `addWound`.

`overlayStateTotal(wound)` = сумма сил (увечье с **этого** удара — ок). Кровопотеря — только `bleedTotal`.

Два ключа на действии: ОД писать в оверлей **исполнителя** (`spendActionPoints` + `setCombatResource`), рану — в оверлей **цели**.

## 4. Этапы

### A — модель и чистая арифметика (Character или Game)

Класс `WoundInstanceService` (хозяин — **Game**: бой и оверлей; DTO `wound` на `CharacterStateValue`, потому что состояние листа). Сигнатуры в духе:

- `migrate(state)` / `migrateVersion(states)`;
- `closure(state, heldActive)`;
- `tick(state, heldActive)`;
- `bleedTotal(states)` — `heldActive` из sidecar `heldBy`;
- `heldCount(actorKey, overlays)`;
- `clampToStrength(state)`;
- `canSqueeze` / `canBandage(state, medicHasAid)`;
- `bandageOd({ medicHasAid, medicHasQuick, targetBandagedOnce })` → 8 | 4 | 2 (спорая без помощи не даёт 2);
- `applyBandage(state, medicHasAid)`;
- `applyClotting(state, rating)`.

Тесты без Vue: тик 4−0=4; перевязка +2 с капом 4; aided снимает кап; зажим даёт минимум 1 и не пишет вклад; внутренняя — нельзя; clamp после падения силы; сумма двух ран; миграция голого `value`.

### B — запись и конец хода

- Хелпер `addWound(strength)` вместо голого `{ value }` в Hit / SpellCast / `EndOfTurnDotsService.addNumericState` для `wound`.
- `applyTurnWoundBleed`: свёртывание (чат + бросок, merge version) → bleedTotal → `applyBloodLossTick` → DOT как сейчас.
- `check-blood-clotting` в каталог + `CHECK_CODES`; не launchable в диалоге.
- Описание состояния `wound` в каталоге: сила/закрытость, не «сумма ран в кровопотерю как value».
- Три копии `applyCombatState` (Hit / SpellCast / EndOfTurnDots) сводятся к `addWound` в сервисе.

### C — действия и карточка

Раны на карточке — обычные тайлы независимого состояния. Попап: вклады, тик, внутренняя, зажата, сила, отпустить (0 ОД), убрать. Перевязать / Зажать — каталог `type: action`, зона `or` `automatic` (`perevyazat`, `zazhat`). Запуск из «Действий»: цель + рана(ы), ОД 8/4/2 и 2×число из `WoundInstanceService` / `WoundActionLaunchService`, не отдельные кнопки помощи/спорой. Константы ОД — `Game/Constant/Wound/`.

Перевязка **не** процесс. Если ОД не хватает — **долг ОД** (`CommittedActionSession`): списать всё доступное, эффект только когда remaining = 0. Не растягивать атаку, реакцию, процесс, variable cost (`wait`). Пока сессия висит — другие действия нельзя (как процесс); wait / передать ход / оборвать / уклон / блок — срыв, ОД не возвращаются. Игнор удара сессию не трогает. Начало своего хода: диалог «Продолжить / Бросить». Взаимно исключает процесс.

### D — спорая и первая помощь

Читать abilities исполнителя (`pervaya-pomosch`, `sporaya-perevyazka`) с `effectiveVersion`. Флаг `woundBandagedOnce` ставить после **успешной** перевязки цели.

## 5. Тестовый минимум

- миграция `{ value: 4 }` → тик 4;
- две раны 3 и 1, без вкладов → Δ крови 4 (как сейчас сумма, пока закрытость 0);
- перевязка без помощи: 2+2 и стоп на 4; третья не поднимает вклад;
- с `pervaya-pomosch`: ОД 4, кап снят, вклад может расти до силы;
- спорая: первая перевязка цели 8/4, вторая любой раны той же цели 2; другая цель снова 8/4;
- зажим: без вкладов тик = сила−1 пока держат, без зажима тик = сила; после отпуска без минимума; 0 ОД — отказ; две раны той же цели = 4 ОД и два `heldBy`;
- свёртывание: 1 куб vs {0|0}, 6 и 1 с предка; нет `rule-blood-clotting` — шаг пропущен; жетон не спрашивать;
- canBandage у капа +4 без помощи false, с помощью true;
- внутренняя: canBandage/canSqueeze false; свёртывание +РУ проходит;
- нет `rule-blood-clotting` → свёртывания нет;
- DOT-тик горения по-прежнему может **добавить** новую внешнюю рану; сама рана DOT-уроном не бьёт.
