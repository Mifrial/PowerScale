## 1. Канон

Один множественный навык **«Знание о…»** (код `znanie`). Три уровня: осведомлён / эксперт / мастер. Цена **1 / 2 / 2** ОР. Признак `knowledge`. Метод интеллекта (`method-intellect`).

Экземпляр — знание в сфере, не практика. Не даёт лечить, варить, резать, собирать. **Никакой навык не выдаёт знание грантом.** Зажать и перевязку (включая первую помощь и спорую) вид **не** режет. Хирургия, уход, варка, сбор, питание **требуют** подходящий экземпляр на якоре ситуации.

Экземпляр: **тип знания** из словаря + **слоты, которые этот тип требует**. Не плоский список меток и не один `domain_ref`. В каждом слоте — **код из словаря слота или свободный текст** (как сейчас у домена: `domainCode` или `domain`). Оба варианта в первом срезе.

Именованные текущие знания — **шаблоны**: фиксируют тип; игрок заполняет слоты. Не отдельные навыки и не вторая система рядом с `znanie`.

Проверка знания: **Память** против сложности. Уровни знания **не** поднимают Память (ни на размер, ни плоским бонусом к характеристике). Текст «Интеллект увеличен на X размеров» у болезней — выкинуть.

У факта две оси:

| Ось | Смысл |
| --- | --- |
| Сложность | Насколько факт спрятан, криво описан, редок как улика. Задаёт мастер (база у шаблона болезней: 2 / 4 / 8). |
| Полоса 1–3 | Насколько это специализация. Совпадает с уровнем, который «должен» быть, чтобы ответить полно. |

`уровень` — максимум из: (а) точный матч типа и слотов (код с кодом; свободный текст со свободным текстом, trim); (б) близкий вид; иначе **0**. Точный слабый не бьёт более сильный близкий.

**Близкий вид** (слот `species`: физиология, болезни, и практика, которая их читает): у цели и у слота есть **коды** вида, у карт общий keyword **типа тела** (`humanoid` и аналоги, не любой тег вроде хищника) — берут уровень экземпляра **на размер ниже** (`уровень − 1`, минимум 0). Свободный текст без кода не шарится. Соседний **регион** этим не покрывается.

```text
нехватка = max(0, полоса − уровень)
сложность' = сложность, повышенная на нехватка размеров
```

Нехватка **1** — место внезапного успеха. Нехватка **2–3** — почти стена без 6/1 и преимуществ. Списание нехватки размером Памяти **не берём**.

Успех при нехватке > 0 — **неполный** ответ, пока не выпала «6» по правилу 6 и 1.

Тот же тип и другой якорь без близости — другой экземпляр, не «частичные метки».

Два экземпляра с одним типом и теми же значениями слотов запрещены.

## 2. Словарь: тип задаёт схему

Словарь **не** мешок строк. Сначала выбирается тип знания; тип объявляет слоты. Без схемы UI не рисует произвольные метки.

Как у текущего `domain_ref`: у слота есть справочник → селект **и** свой текст; справочника нет → только текст.

### 2.1 Типы (`knowledge_field`)

Карточки справочника (не keyword). Для миграции:

| Код | Имя | Обязательные слоты |
| --- | --- | --- |
| `laws` | Законы | `region` |
| `animals` | Животные | `region` |
| `plants` | Растения | `region` |
| `history` | История | `region` |
| `diseases` | Болезни | `species` |
| `physiology` | Физиология | `species` |
| `other` | Прочее | `topic` — о чём (только текст) |

`other` — не прописанные знания на игре. Не второй навык.

Тип без заполненных обязательных слотов купить нельзя. Шаблон подставляет тип, слоты всё равно обязательны.

### 2.2 Слоты

| Ключ | Опции селекта | Свой текст |
| --- | --- | --- |
| `species` | правила ревизии `type: 'species'` | да |
| `region` | те же, что `domain_ref: 'region'` | да |
| `topic` | нет | обязателен |

Опции — существующие карты `domainOptionsOf`. Новую ось `domain_ref` не плодить, если слот уже есть.

```text
knowledge_field:
  slots:
    - key: region
      required: true
      domain_ref: region
      allow_custom: true
```

Несколько слотов у одного типа схема допускает; миграция — один обязательный якорь.

### 2.3 Экземпляр на листе

```text
ruleCode: znanie
level: 1..3
fieldCode: physiology
slots:
  species: { code: 'elf' | null, text: 'Эльфы' }
```

Подпись: «Знание о физиологии · Эльфы». На листе живёт `znanie`, не отдельный навык физиологии.

## 3. Разбор каталога

Правило: **знание вспоминает, навык делает.** Знание — метод интеллекта. Сбор трав — метод восприятия. **Грантов знания из практики нет.**

### 3.1 Чистое знание → шаблон `znanie`

| Было | Тип | Слот | Что делаем |
| --- | --- | --- | --- |
| `znanie-zakonov` | `laws` | `region` | Навык убрать. Шаблон. Было 2 ОР / 1 ур. → уровень 1 лестницы 1/2/2 |
| `znanie-o-zhivotnykh` | `animals` | `region` | То же |
| `znanie-o-rasteniyakh` | `plants` | `region` | То же. Отдельный код «знание трав» не вводить |
| `znanie-o-istorii` | `history` | `region` | То же |
| `znanie-bolezney` | `diseases` | `species` | Шаблон. 1/2/3 → **1/2/2**. DC 2/4/8 у проверки. Снять баф Интеллекта. Назвать средство ≠ сварить |
| `fiziologiya` | `physiology` | `species` | **Навык удалить.** Шаблон 1/2/2, как болезни. Лестницу 2/4/4 не переносить |
| `predpisaniya-o-lechenii` | — | — | **Навык удалить.** Исполнение чужого назначения — уход (+ физиология + бумага/рецепт), не покупка |

### 3.2 Практика без домена вида/региона

Один навык на персонажа. Вид и регион **не** покупаются на этих карточках. Уход / хирургия / варка / сбор / питание смотрят знания цели или места. Перевязка — нет.

| Код | Сейчас | Решение |
| --- | --- | --- |
| `farmatsiya` | multiple + вид, 1/2/4 | Снять `domain_ref`. Своя лестница. Варить для вида — `physiology` вида **и** `plants` региона травы |
| `khirurgiya` | multiple + вид; старый предел 5 | Снять `domain_ref`. Проверка: мелкая моторика + уровень навыка + `physiology` цели. Дети без домена |
| `pervaya-pomosch` | multiple + вид, 1 ОР | Снять `domain_ref`. **Без** знания вида. Дети: только `sporaya-perevyazka` |
| `ukhod` | multiple + вид | Снять `domain_ref`. `physiology` цели (в т.ч. близкий вид). Именованный курс — `diseases` **или** чужое/книжное назначение (предмет/текст), без отдельного навыка |
| `pitanie` | multiple + вид | Снять `domain_ref`. Программа для вида — `physiology` цели, близкие виды — §1 |
| `poisk-trav` | 2 ОР, энциклопедия + сбор, +3 Внимательность | **1 ОР**, без домена, **без +3**. `method-perception`. Искать в регионе — `plants` этого региона |

### 3.3 Практика рядом

| Код | Решение |
| --- | --- |
| `zaschita-ot-zakona` | Живой. Привязка к экземплярам `znanie`/`laws`. Бонус по известным регионам |
| `obnaruzhenie-dobavok` | Распознать траву — `plants` |
| `chtenie-sledov` | «Знает о волках» → `animals` |
| `fizika` | Прикладной навык, не `znanie` |
| `estestvoznanie` | Гейт без слота. Не `znanie`, не `knowledge` |
| `bookworm` | Бесплатный экземпляр `znanie` **любого** типа (слоты заполняет игрок) или письменность. Не хирургия |
| шифр / математика / счёт / торговля / этикет | Не эта система. Торговля **оставляет** `region`: это рынок, не энциклопедия |

### 3.4 Не эта система

`zaschita-znaniem`, `adaptatsiya-k-protivniku` — память боя. Характеристика `medicine` — вторичка дампа, не `znanie`.

Требования практики — `has_knowledge` (тип + слоты **ситуации** + min_level), не `has_ability` на удалённый `fiziologiya`.

Миграция листа: экземпляр старой физиологии вида → `znanie`/`physiology` того же вида, `min(уровень, 3)`. Несколько экземпляров первой помощи/ухода/питания/фармации/хирургии по видам → **один** навык (максимум уровня).

**Разово при миграции** (это не грант навыка): для каждого вида, который был доменом живой практики **кроме** первой помощи, если ещё нет `physiology` этого вида — создать уровень **1**. Иначе уход/хирургия/варка/питание «есть на листе», а применить не к кому. Перевязка без знания вида работает и без этого. Растения с доменов фармации/сбора не выдумывать (у фармации домен был вид, не регион).

## 4. Медицина как игра

Вид на листе выбирается **только** в знаниях. Практика одна на персонажа. Ниже — что за стол происходит, не runtime этого среза.

### 4.1 Две оси знания тела

| Тип | Вспоминаете | Не даёт |
| --- | --- | --- |
| `physiology` | Как устроено тело вида: кости, кровь, что будет если резать/кормить | Перевязать, оперировать, варить |
| `diseases` | Узнать болезнь, назвать чем лечить (трава/мазь/режим) | Изготовить лекарство, провести курс |
| `plants` | Трава региона: вид, свойства, где растёт | Собрать, сварить |

Опознание болезни — проверка знания (`diseases` + вид), DC 2/4/8, нехватка уровня → +размер. Полнота «как в этом теле» — если эффективная `physiology` цели ≥ 1 (точный или близкий вид). Иначе название без посадки в тело. Покупку `diseases` без физиологии не блокировать.

### 4.2 Рана: сила и закрытость

У **каждой** раны два числа, не одно агрегированное «wound» как сейчас.

| Поле | Смысл |
| --- | --- |
| Сила | Тяжесть. Падает **−2 в сутки**. Зажим / перевязка / свёртывание силу не трогают. После падения силы закрытость (и вклады) сразу **clamp** к новой силе |
| Закрытость | Сумма вкладов, не выше силы. Тик крови = **сила − закрытость** (≥ 0) |

Вклады закрытости **раздельные**:

| Источник | Вклад | Потолок вклада |
| --- | --- | --- |
| Перевязка | +2 за действие | Пока рану ни разу не перевязали **с первой помощью**: вклад перевязки **не больше +4**. После такой перевязки потолок снят (до силы). Вид не нужен |
| Свёртывание крови | +РУ с проверки правила | **Нет** капа, только не выше силы. В том числе внутренние |
| Зажать | пока рука: закрытость считается минимум 1 | не пишет в перевязку. Одна рука — одна **внешняя** рана; две руки — две. Внутреннюю зажать нельзя |

Свежая рана: закрытость 0. **Внутреннюю** перевязать нельзя (нужна хирургия, после успеха рана становится обычной).

**Свёртывание крови** — простое **правило** каталога (не хардкод Game). Механика: в конце хода раненого по **каждой** ране (включая внутреннюю) проверка **[1] против 0**; успех — вклад свёртывания этой раны +РУ (не выше силы; капа перевязки нет). Нет правила в ревизии — свёртывания нет. Как `rule-6-and-1`. Code: `rule-blood-clotting`. Проверка — наследник простой.

**Зажать** (любой): 2 ОД за рану, свободная рука. Две свободные руки — две **внешние** раны сразу. Внутреннюю зажать нельзя. Пока держите: итог закрытости этой раны минимум 1. Отпустили — бонус зажима этой раны пропадает.

**Перевязать** — одно действие для всех, **без** знания вида. +2 к вкладу перевязки. База **8 ОД**. Без первой помощи на этой ране вклад перевязки стопорится на **+4** (две перевязки). Перевязка **с первой помощью** снимает кап; дальше можно набирать +2 до силы. Первая помощь — модификатор (§4.4), не отдельный экшен.

Закрытость не выше силы. Полностью закрытая рана — всё ещё рана.

Текущий мок `wound` как одно число — не этот канон. Game: экземпляр раны. Не срез 5.1 листа.

### 4.3 Практика: разные минуты стола


Не сливать в один «медик». Иначе полевой санитар и хирург — одна кнопка.

| Навык | Когда | Знания в момент применения | Покупка |
| --- | --- | --- | --- |
| Первая помощь | Улучшение перевязки: нет потолка +4; 8 ОД → 4 ОД | не нужно | 1 ОР, без домена |
| Спорая перевязка | Улучшение **первой помощи** (без неё не взять) | не нужно | После первой перевязки **этого персонажа** следующие перевязки **любых его ран** — 2 ОД |
| Уход | Длинный отдых: доп. −1 истощения | `physiology` цели (близкий вид — §1); болезнь — `diseases` или назначение | 1 ОР, без домена |
| Хирургия | Вскрыть, достать, ампутировать, кость | `physiology` цели (близкий вид — §1) | Своя лестница 1–3, без домена. **Не** требовать первую помощь на покупку. Проверка: пул **мелкая моторика + уровень хирургии + физиология цели** против сложности операции (мастер/сцена; таблицу операций не пишем). После операции кто-то стабилизирует (помощь/уход) |
| Смертоносные удары | Ребёнок хирургии: помеха/преимущество на увечье | эффективная `physiology` жертвы ≥ 1 (в т.ч. близкий вид) | как сейчас |
| Фармация | Сварить средство | `physiology` вида пациента (близкий — §1) **и** `plants` региона ингредиента. *Что* варить под болезнь — из `diseases` или из предписания; без этого только общее («мазь на рану») | лестница 1/2/4, без домена |
| Сбор трав | Найти и снять растение | `plants` региона | 1 ОР, метод восприятия |
| Питание | Программа на недели: тело / вес / больной | `physiology` цели (близкий вид — §1); «для больного» осмысленно с `diseases` | 2 ОР, без домена |

Хирургия: §4.4. Не перевязка и не −сила за ход боя.

### 4.4 Механика (текст карточки)


Строки с * в выгрузке не было — предложение, чтобы навык игрался в уже существующих состояниях (кровопотеря, рана, истощение, увечье).

**Знание о физиологии** (`znanie` / `physiology`, вид, 1/2/2).  
Проверка: Память против сложности факта. Нехватка уровня → сложность на столько размеров. Успех: ответ по полосе уровня. Не лечит. Без него (и без близкого вида) не включаются хирургия/уход/варка/питание по этому виду. Перевязка, первая помощь и спорая — без этого требования.

**Знание о болезнях** (`diseases`, вид, 1/2/2).  
Проверка: Память. База: обычная болезнь 2, редкая 4, очень редкая 8. Нет ярких симптомов — сложность +размер; без описания симптомов — ещё +размер; ложное описание — плюс две помехи. Успех: опознать и **назвать** обычное лечение (трава/мазь/режим). Не даёт дозу и не проводит курс. Без эффективной физиологии цели ≥ 1 (точный или близкий вид) успех неполный (название без «как это в этом теле»).

**Знание о растениях** (`plants`, регион, 1/2/2).  
Проверка: Память. Успех: узнать растение региона, свойства, где искать. Не сбор и не варка.

**Первая помощь** (1 ОР, без домена). Родитель спорой.  
Не новое действие. Модифицирует **Перевязать** на любом виде: 4 ОД за +2 вместо 8 **и** снимает кап +4 **на этой ране**. Свёртывание крови не ограничивает.

**Спорая перевязка** (1 ОР). `parent_ability_code: pervaya-pomosch`, без первой помощи не купить. Выгрузку «−2 ОД от мастерства» не берём.  
После первой перевязки **этого персонажа** (любая его рана) следующие перевязки **всех его ран** стоят **2 ОД**. Первая перевязка на нём — полная (8 или 4). Другой персонаж — снова полная цена.

**Уход** (1 ОР, без домена).  
Нужна эффективная физиология цели ≥ 1 (близкий — §1). Длинный отдых: ещё **−1 истощения**. Силу раны не режет (−2/сутки — само). Недуг — знание болезней или назначение. В бою раны не закрывает.

**Хирургия** (уровни 1–3, без домена).  
Нужна физиология цели ≥ 1 (или близкий вид). Операции. Проверка: пул **мелкая моторика + уровень хирургии + уровень физиологии цели** против сложности операции (задаёт сцена; таблицу уровней 1–3 не расписываем).  
Внутреннюю снаружи не перевязать; успех операции делает рану обычной (дальше зажим/перевязка). Силу за операцию не снимает (сила −2/сутки). Провал — новая рана/увечье. Первую помощь на покупку не требовать.

**Смертоносные удары** (1 ОР, ребёнок хирургии).  
Когда вы наносите увечье виду, чью физиологию знаете: помеха **или** преимущество на **эту** проверку увечья (выгрузка).

**Фармация*** (1/2/4, без домена).  
Варить для вида пациента — эффективная физиология ≥ 1 (близкий — §1); ингредиент — знание растений региона травы ≥ 1. Время*: не бой, сцена. Проверка*: Интеллект, сложность 2 + размер за редкость средства (как полоса болезней, если варка под болезнь).  
Успех: одна доза, качество = РУ. Под болезнь — только если есть знание болезней этого вида или готовое назначение; иначе только общее («мазь на рану», не именной недуг). Провал: ингредиенты тратятся, дозы нет.

**Сбор трав*** (1 ОР, `method-perception`).  
Нужно знание растений региона ≥ 1. Проверка: Внимательность, сложность 2* (местность хуже — мастер +размер). Успех: найти и собрать знакомые травы; сколько/какие — РУ и знание (мастер). Без знания региона проверку не объявлять. Бонуса +3 к Внимательности больше нет.

**Питание** (2 ОР, без домена).  
Нужна эффективная физиология цели ≥ 1 (близкий — §1). Не проверка «вспомнить еду» — три программы из выгрузки:  
1) развитие тела: большая часть времени на «Физическое развитие» — стоимость черты −1, минимум 2; еда 6 ГЗ/мес при создании;  
2) похудение без вреда здоровью;  
3) для больного/слабого пищеварения — осмысленно с знанием болезней или назначением.  
Близкие виды — §1 (keyword типа тела вроде `humanoid`, уровень − 1).

### 4.5 Что не смешивать

- Закрытость ≠ сила. Потолок +4 — вклад **перевязки**, пока рану не перевязал медик с помощью; свёртывание без капа (в т.ч. внутренние).
- Внутреннюю не перевязать и не зажать, пока хирургия не сделала её обычной. Свёртывание внутренние трогает.
- Первая помощь / спорая — модификаторы перевязки, не свои кнопки; **вид не нужен**.
- Спорая без первой помощи не взять.
- Зажать ≠ перевязать (рука vs конечное действие).
- Помощь ≠ уход (бой ≠ длинный отдых).
- Знание болезней ≠ фармация.
- Физиология ≠ хирургия: понять тело ≠ оперировать; хирургия ≠ перевязка.
- Готовое назначение — не навык.
- Характеристика `medicine` в дампе — не этот контур.

- Списание нехватки размером Памяти.
- Runtime варки/операции/сбора.
- PHP до контракта слотов в бою.
- Слот `subject`.

## 7. OPEN

Нет живых продуктовых дыр на этот скоп.

## 8. Скрытые дыры (не забыть)

**Экземпляр знания не влезает в `domain`/`domainCode`.** Язык — один домен. Знание — `fieldCode` + слоты.

**`parent_ability_code: 'znanie'` нельзя.** Защита от закона — фильтр типа `laws`.

**Требование практики — ситуация, не покупка.**

**Код вида vs свободный текст.** Точный матч — код с кодом. Близость — общий keyword **типа тела** (`humanoid`); голый текст не шарится.

**Методы интеллекта.** Каждый инстанс `znanie` — метод 1/2/2; старая физиология 2/4/4 методом не была.

**Коды-шаблоны.** Снимки/`fiziologiya`/`znanie-zakonov` — жёсткая миграция или алиас.

**Рана в Game.** Экземпляры сила + вклад перевязки + вклад свёртывания. Тик = сила − закрытость. Правило `rule-blood-clotting`. Накопленная кровь — сумма тиков.

**5.1 не закрывает раны.** Лист знаний без боя; раны — отдельный Game-срез.
