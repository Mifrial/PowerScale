## 3. Канон первой пачки

Источник помехи Обоерукой — **не обстоятельства**. Код источника: `multi_attack`, подпись «множественная атака» (`ADVANTAGE_SOURCE_MULTI_ATTACK`). Бой в нескольких руках уменьшает **этот** источник на любой атаке, где он есть, не общий пул обстоятельств.

### 3.1 `oboerukaya-ataka`

4 ОД, 2 ОР, keyword 71, окно «Атака». Итоговая стоимость **не ниже 3 ОД** (пол этой карты). Пол прочих атак — 2 ОД.

> Совершите два последовательных удара разным оружием с одной помехой от множественной атаки. Если следующее действие — атака по той же цели, её первый удар получает +1 к точности.

- Два **последовательных** удара (у каждого своя реакция). Не wide. Не `rollSimultaneousHits` с ignore на втором.
- Оружие второго удара ≠ оружие первого (экземпляр экипа, не «два профиля одного предмета»).
- На **каждый** удар: −1 к попаданию, источник `multi_attack`.
- Хвост: pending `next_action_attack_accuracy` { delta: 1, same_target, scope strike / hit_count 1 }.
- Спека: `min_total_action_cost: 3`.

### 3.2 `boy-s-oruzhiem-v-neskolkikh-rukakh`

Skill, 2 ОР, **не** `parent_ability_code`. Самостоятельный навык секции Количество.

Требования (оба): `has_ability` `blizhniy-boy` min 2 («Навыки боя»); `has_ability` `oboerukaya-ataka` min 1 (открывает ветку).

> −1 помеха от множественных атак.

Действует на **любую** текущую атаку, у которой уже есть помехи источника `multi_attack`: уменьшает их число на 1 (не ниже нуля по этому источнику). Не привязан к карточке Обоерукой. Налог повторного оружия в процессе Множества ударов — обстоятельства, **не** гасится.

### 3.3 `mnozhestvo-udarov`

Process, 2 ОР, keyword 71. Требование: `has_ability` Обоерукая (не Ближний бой, не «Двойной удар» посоха).

> Процесс начинается ударом за 3 ОД; каждая следующая часть стоит 2 ОД. Промах завершает процесс. Для удара используется столько помех от обстоятельств, сколько раз соответствующее оружие уже использовалось в процессе ранее.

Шаги (описание карточки — канон; шаги не дублируют формулу иначе):

| Шаг | ОД | Удар |
| --- | --- | --- |
| Первая часть | 3 | один удар; промах рвёт процесс |
| Часть | 2 | один удар; промах рвёт; можно повторять |

Граф как у Серии: `part-1 → part-2`, `part-2 → part-2`. Не `chain both`. Прерывание `normal`. Completion нет.

Помехи **обстоятельств** на этот удар = число **уже завершённых** ударов **этим экземпляром** в этой сессии (первый удар оружием — 0). Счётчик на `ProcessSession`, не код правила предмета.

## 3a. Канон спец-пачки

Не Обоерукая: не sequential, не разные оружия, не две реакции.

### 3a.1 `sdvoennyy-udar`

Action, 3 ОД, 2 ОР, keyword 71, окно «Атака». Требование: `has_ability` `oboerukaya-ataka` min 1 (не «Навыки боя» 1 как в старом моке).

> Один удар в одно место несколькими экземплярами **одинакового** оружия. Одна проверка попадания против одной защиты. При успехе число попаданий = число экземпляров. Помехи источника `multi_attack` = число экземпляров. Без навыка «Оружия много — удар один» экземпляров ровно 2.

- Одна цель. Не wide. Не sequential. Не две независимые реакции.
- Экземпляры **одинаковые**: один `itemRuleCode` (две руки, два кинжала, два копыта). Рука+нога / меч+кинжал — нет, это Обоерукая.
- Различаются `instanceIndex` / `inventoryItemId`, как уже у стопки quantity.
- Промах — ни одного попадания. Успех — N пакетов урона профилей выбранных экземпляров (у одинакового оружия профили совпадают).
- `multi_attack` −N на эту одну проверку (N=2 без навыка). «Бой в нескольких руках» гасит 1, как на любой атаке с этим источником (−2 → −1).
- Старый текст (min точности, объединение помех «хотя бы с одного», +1 обстоятельство за голову) — снят.
- Спека (ориентир): `same_weapon: true`; `min_weapons: 2`; `max_weapons: 2` пока нет навыка; `action_effects` `current_action_check_modifier` source `multi_attack` с delta = −N (N с запуска, не константа −2 в карточке, если N потом > 2).

### 3a.2 `mnozhestvo-ruk` — «Оружия много — удар один»

Skill, 1 ОР, **parent** `sdvoennyy-udar` (покупка только со Сдвоенным; Обоерукая — через родителя).

> Снимает кап «ровно 2 экземпляра» у Сдвоенного удара. Можно взять столько одинаковых экземпляров, сколько есть.

Не поднимает `characterHandCount` и не открывает третью руку экипа. Человеку с двумя копиями одного природного оружия навык ничего не даёт — так задумано. Живёт, когда копий ≥ 3 (лишние конечности, стопка природного оружия, позже лимит рук с другой карты).

Не гасит `multi_attack`. N растёт — налог `multi_attack` тоже.

## 4. Что уже есть в Game

- Слоты рук и лимит 2; Обоерукая человеку **не** ждёт снятие капа Сдвоенного.
- `strike_count` / `distinct_weapons` в спеке; AttackLaunch даёт N слотов, разный `inventoryItemId`.
- `reactionMode: 'sequential'`: каждый удар бросается своим попаданием; отдельная реакция на удар посажена.
- Хвост `next_action_attack_accuracy`; пол `min_total_action_cost`.
- Wide и `rollSimultaneousHits` без изменений.
- Process Серии есть. Счётчик экземпляра оружия в Множестве ударов посажен. Гашение `multi_attack` от навыка посажено.

## 5. Посадка Game

```text
A. Источник multi_attack + подпись — в спеке/лейбле
B. Два последовательных слота — посажено
C. Пол min_total_action_cost этой карты — посажено (глобальный пол 2 ОД прочих атак нет)
D. Хвост next_action_attack_accuracy — посажено
E. −1 multi_attack от навыка (любая атака с этим источником) — посажено
F. Множество ударов: счётчик экземпляра — посажено
G. Отдельная реакция на каждый последовательный удар — посажено
H. Сдвоенный: один бросок / одна защита / N попаданий / same_weapon / −N multi_attack — посажено
I. Кап max_weapons=2 и снятие капа навыком — посажено
```

Тесты Game — синтетический `Rule`, не коды мока.

## 6. Порядок работ спец-пачки

```text
1. Мок: вырезать sinkhronnaya-ataka (как balans).
2. Мок: Сдвоенный — текст, 3 ОД, требование Обоерукая, same_weapon, кап 2, multi_attack −N.
3. Мок: mnozhestvo-ruk → имя «Оружия много — удар один»; parent Сдвоенный; снятие капа; не слоты рук.
4. Game: запуск Сдвоенного — выбор N=2 одинаковых экземпляров, одна цель.
5. Game: один hit vs одна защита; успех → N уронов; промах → 0.
6. Game: помеха multi_attack = −N; навык Бой в нескольких руках уже гасит 1.
7. Game: навык «Оружия много — удар один» снимает max_weapons=2 (N = сколько одинаковых экземпляров есть).
```

Не смешивать с sequential Обоерукой и не звать `rollSimultaneousHits` как wide по нескольким целям.
