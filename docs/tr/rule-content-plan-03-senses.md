# C2 — обсуждение: чувства и освещение

**Статус:** `DEFERRED`. Спека и лист есть; **Game чувства не читает, в текущий релиз не входит.**  
**Родитель:** [`rule-content-roadmap.md`](rule-content-roadmap.md).  
**Очередь:** [`rule-content-queue.md`](rule-content-queue.md).  
**Карточки:** `sense-hearing`, `sense-vision`, `dark-vision`.

Батлмапы нет и не будет скоро. Освещение сцены и радиус чувств в Game **не** строить, пока явно не откроем срез.

## Канон освещения

| Код | Смысл |
| --- | --- |
| `good` | Хорошее освещение |
| `dim` | Слабое освещение (сумерки) |
| `minimal` | Минимальное освещение (ночь в лесу) |
| `none` | Без освещения |

Обычное Зрение рассчитано на хороший свет. Штрафы сумерек и полной тьмы — когда появится чтение освещения в Game.

## Ночное зрение (`dark-vision`, имя карточки)

Не D&D-darkvision. При **минимальном** освещении Зрение работает **как при хорошем**. **Без освещения черта не помогает.**

Код правила не меняли (раса Турим). В гранте `sense_modify` на `sense-vision`:

```text
treat_as_good_down_to: minimal
```

На инстансе чувства: `treatAsGoodDownTo`. Несколько грантов — берётся более глубокий порог (`none` сильнее `minimal`).

Полноценное зрение в `none` — отдельная будущая черта с `treat_as_good_down_to: none`, не эта карточка.

## Срез сделан

Спека, редактор гранта, попап чувства, миграция старой галочки `darkVision` → `minimal`. Game радиус и освещение **не** читает и не должен, пока не откроем отдельный срез после релиза.

## OPEN (не этот срез)

- где живёт освещение без карты (флаг сцены / участника);
- что сумерки делают с обычным зрением;
- какие броски режет тьма;
- радиус 30 — ипари или нет.
