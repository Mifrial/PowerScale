# Ревью фронта — индекс волн

Оглавление по волновым контекстам `docs/review/`. Создан 2026-08-05 в рамках
упорядочивания ревью-документации (context-17).

## Как читать

- **`context.md`** — историческое ревью ТР/фронта (2026-08-01…02): фазы 0–5,
  сводная таблица F1–F42 (закрыта), решения по каждой проблеме. Источник
  найденных тогда противоречий ТР (TR-1…TR-8).
- **`context-N.md`** — волновые ревью модулей по одному модулю/группе за волну.
  Это **аудит-трейл** решений: найденное, варианты, принятый выбор и правки.
- **Канон принятых решений** — `docs/tr/TR.md §13 «Решения с фронта»`
  (архитектурные решения фронта) и основной текст ТР (контракты/потоки). При
  расхождении волнового контекста и ТР истинен **ТР**; контекст при необходимости
  помечается.
- Промт волны — `docs/review/prompts/review-module-prompt.md`.
