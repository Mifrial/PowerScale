# Стартовый набор декора

Собственные спрайты проекта, сгенерированные процедурно для сцен:

- `tree.png` — дерево, 256×340, якорь снизу по центру;
- `bush.png` — куст, 200×160;
- `boulder.png` — валун, 240×180, видимая масса 174×101 в точке (40, 59);
- `rock.png` — старый камень, 200×140: оставлен только для уже загруженных
  ассетов, новым набором не используется.

Лицензия: CC0 / public domain, ограничений на использование нет.
Файлы не подключаются кодом: их загружают в общую коллекцию `decor`
библиотеки ассетов (`Library/Asset`), а элемент декора хранит только
`assetPublicId`. План — `docs/tr/asset-library-plan-01.md`.

Прозрачные поля не задают физику и не сбивают якорь: сервер считает видимую
рамку картинки при загрузке (`file.content_box`), а сцена ставит на якорь низ
видимой массы и считает `scale` от видимой ширины. Поэтому у нового спрайта
достаточно оставить прозрачный запас, не подгоняя картинку под точку.
